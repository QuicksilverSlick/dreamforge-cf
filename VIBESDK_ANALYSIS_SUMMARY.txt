ARCHITECTURE DECISION RATIONALE
================================================================================

WHY DETERMINISTIC ORCHESTRATION:
  + Clear, sequential workflow (easy to debug)
  + Predictable resource usage
  + State is always consistent
  + Perfect for Durable Objects

WHY SEPARATE OPERATIONS:
  + Single responsibility principle
  + Easy to test in isolation
  + Easy to swap implementations
  + Easy to monitor individually

WHY STREAMING WITH SCOF:
  + Handles 100MB+ codebases without OOM
  + Progressive UI updates
  + Network efficient
  + Error recovery at file level

WHY RETRY WITH MODEL DOWNGRADE:
  + Recovers from transient failures
  + Cost optimization (50-70% savings)
  + Preserves partial context for recovery
  + Intelligent recovery path

WHY DURABLE OBJECTS:
  + Automatic persistence
  + Fault tolerance (survives crashes)
  + Natural scale unit
  + Simplifies state management

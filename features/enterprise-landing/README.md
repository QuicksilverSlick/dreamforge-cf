### Color Psychology Reasoning:

- **Purple (#667EEA):** Trust, innovation, enterprise-grade (associates with tech giants like Stripe, Twitch)

- **Green for ROI:** Universal success/money color, triggers financial benefit association
- **Orange for Urgency:** Warm, action-oriented without being aggressive
- **Red for Stakes:** Creates discomfort (pain points) that purple/green resolve

## 💰 Psychological Pricing Strategy

### Principles Applied:

#### 1. **Charm Pricing**
- $297 (not $300) - Perceived as $200-range not $300-range
- $497 (not $500) - Original price anchor
- $97 per additional member (not $100)

#### 2. **Anchoring**
```
Original: $497/month ← Anchor (establish high value)
BETA: $297/month    ← 40% discount feels massive
Savings: $200/month ← Explicit calculation helps
```

**Effect:** Customer sees $297 as deal, not evaluating if it's worth $297

#### 3. **Loss Aversion**
- "40% OFF BETA PRICING" - fear of losing discount
- "Limited to 50 Businesses" - scarcity
- "Then $497/mo" - explicit future loss
- "First 50 businesses only" - exclusivity loss

#### 4. **Decoy Effect**
```
3 people: $297/mo  ← Target (best value)
4 people: $394/mo  ← Decoy (per-person cost drops)
21+ people: Custom ← Aspiration (enterprise tier)
```

**Effect:** Makes $297 for 3 people seem like best value

#### 5. **Volume Pricing Psychology**
```
Member 4-10: $87/mo each  (10% discount)
Member 11-20: $77/mo each (21% discount)
Member 21+: Custom        (maximum savings)
```

**Effect:**
- Encourages multi-seat purchase
- Tiered rewards feel like "leveling up"
- Custom tier creates enterprise aspiration

#### 6. **Value Metrics**
Price anchored against alternatives:
- vs. Developer: "$80-150K/year" (makes $297/mo = $3,564/yr seem tiny)
- vs. SaaS Tools: "$30,000/year wasted" (10x ROI in first year)
- vs. Competitors: "Training Included: ✅ vs. ❌" (exclusive value)

#### 7. **Guarantee as De-Risking**
- "30-day money-back guarantee"
- Reduces perceived cost from $297 to $0 (risk-free trial perception)
- Increases conversion 20-30% typically

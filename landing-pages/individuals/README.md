# Dreamforge Individual Landing Page

Complete landing page targeting individuals who want to build, deploy, and monetize apps for recurring income.

## Overview

This landing page follows the **StoryBrand Framework** strictly to convert worried individuals into empowered builders making money from apps.

### Target Audience
- Individuals worried about AI taking their jobs
- Aspiring entrepreneurs/"vibe coders"
- People wanting recurring income from SaaS products they build
- Non-technical founders who want to monetize app ideas

### Key Transformation
**From**: Worried about AI replacing jobs → **To**: Empowered builder earning $1K-$10K MRR

## Setup Instructions

### 1. Local Preview

```bash
# Navigate to landing page directory
cd /home/user/dreamforge-cf/landing-pages/individuals

# Open in browser (use any local server)
# Option 1: Python
python3 -m http.server 8000

# Option 2: Node.js (http-server)
npx http-server -p 8000

# Open: http://localhost:8000
```

### 2. Deployment to Cloudflare Pages

```bash
# Install Wrangler
npm install -g wrangler

# Login to Cloudflare
wrangler login

# Create Pages project
wrangler pages project create dreamforge-landing

# Deploy
wrangler pages publish . --project-name=dreamforge-landing
```

### 3. Custom Domain Setup

1. Add custom domain in Cloudflare Pages dashboard
2. Update DNS records:
   - `CNAME` record pointing to Pages URL
3. SSL certificate auto-provisioned
